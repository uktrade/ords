# ORDS Controlled Vocabulary and Format Mappings

This reference defines canonical values for controlled ORDS properties and the format mapping policy.

## Format Policy

- Canonical metadata value: IANA media type string (for example, application/pdf).
- Optional semantic mapping: corresponding ORDS SKOS concept in the format scheme.

| ORDS label | IANA media type (recommended) |
| --- | --- |
| PDF | application/pdf |
| HTML | text/html |
| MS Word | application/msword or application/vnd.openxmlformats-officedocument.wordprocessingml.document |
| ODF | application/vnd.oasis.opendocument.* (choose the specific subtype) |
| ODT | application/vnd.oasis.opendocument.text |
| Rich Text | text/rtf |

## Coverage

- Use ISO 3166 UK codes.
- Use ASCII hyphen-minus in all compound codes (for example, GB-ENG, GB-WLS).
